# 🚀 Full Stack Portfolio Website

A modern, production-ready portfolio built using Next.js, featuring a responsive UI, smooth animations, and backend integrations for contact and newsletter functionality.

---

## 🔗 Live Demo

👉 https://your-portfolio-link.com

---

## 🛠 Tech Stack

### Frontend

* Next.js (App Router)
* React
* Tailwind CSS
* Framer Motion

### Backend

* Next.js API Routes
* Resend (Email API)

---

## ✨ Features

* ⚡ Fully responsive design (mobile-first)
* 🌙 Light / Dark theme support
* 🎯 Smooth animations using Framer Motion
* 📬 Contact form with email integration
* 🧠 Clean and scalable component architecture
* 🚀 Optimized performance and SEO-friendly

---

## ⚙️ Environment Variables

Create a `.env.local` file in the root:

```
RESEND_API_KEY=your_resend_api_key
```

---

## 🚀 Getting Started

### 1. Clone the repo

```
git clone https://github.com/StanProgrammer/My-Portfolio-Website
```

### 2. Install dependencies

```
npm install
```

### 3. Run development server

```
npm run dev
```

### 4. Open in browser

```
http://localhost:3000
```

---

## 📬 API Endpoints

### Contact Form

```
POST /api/contact
```

### Newsletter Subscription

```
POST /api/newsletter
```
